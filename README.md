# Inturp community files

Shared GitHub templates and contribution guidance for Inturp repositories.

- `profile/README.md`: public organization profile.
- `ISSUE_TEMPLATE/`: bug report and feature request forms.
- `PULL_REQUEST_TEMPLATE.md`: review checklist.
- `CONTRIBUTING.md`: collaboration guidelines.
- `SECURITY.md`: private security reporting guidance.

Repositories can override these defaults with their own files. No open-source license is implied by these templates; each project defines its own license.

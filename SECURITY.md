# Security reporting

Please report suspected security vulnerabilities privately to **info@inturp.com** with the subject `Security report — [project name]`.

Include the affected project/version, a clear description, and minimal reproduction steps when possible. Redact personal data and credentials. Do not include live secrets, customer records, or production database exports.

Please do not disclose vulnerability details in public issues or pull requests. Avoid testing that disrupts services, accesses another person's data, or changes production records.

Project-specific supported versions and security policies, where present, take precedence. We do not currently promise a response deadline or a paid bug bounty.

# Working with Inturp

Thank you for helping improve our projects. Contribution access and scope depend on the individual repository.

## Before starting

- Read the repository README and setup instructions.
- Open a focused issue describing the problem or proposed improvement.
- For substantial changes, agree on scope in the issue before implementation.

## Changes and reviews

1. Create a short, descriptive branch from the current default branch.
2. Keep the change focused and avoid unrelated formatting or dependency updates.
3. Run the checks documented by the project.
4. Open a pull request explaining the problem, resulting behavior, and verification.
5. Include screenshots for visual changes and flag migration or deployment requirements.

Do not commit secrets, customer data, production exports, or credentials. Use synthetic data in examples and tests. Report security concerns privately using `SECURITY.md`.

Use a respectful, constructive tone. Arabic and English are both welcome.

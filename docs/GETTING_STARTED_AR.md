# دليل البداية مع Inturp على GitHub

المؤسسة: https://github.com/inturp

GitHub يحفظ ملفات مشاريعك وتاريخ تعديلاتها، ويسهّل التعاون. المؤسسة تجمع مشاريع الشركة والأعضاء في مكان واحد؛ وهي ليست تسجيلًا قانونيًا للشركة.

## المصطلحات الأساسية

| المصطلح | المعنى |
| --- | --- |
| Organization | مساحة الشركة التي تملك المشاريع وتدير أعضاءها |
| Repository | مجلد مشروع مع تاريخ التعديلات |
| Commit | نسخة محفوظة من تعديل مع وصف |
| Branch | مساحة لتطوير تعديل قبل دمجه في النسخة الرئيسية |
| Issue | مهمة أو مشكلة أو اقتراح |
| Pull request | طلب مراجعة التعديلات ودمجها |
| Actions | تشغيل عمليات آلية مثل فحص المشروع ونشره |

## إنشاء مشروع

1. افتح المؤسسة ثم Repositories ثم New repository.
2. تأكد أن Owner هو inturp، واختر اسمًا واضحًا مثل company-website.
3. اختَر Private للمشاريع الداخلية أو مشاريع العملاء. اختر Public فقط للملفات التي تريد نشرها للناس.
4. أضف README يشرح هدف المشروع وطريقة تشغيله.
5. استخدم main للنسخة الرئيسية، وأنشئ branch منفصلًا لكل تغيير مهم.
6. افتح Pull request، راجع التغيير واختبره، ثم ادمجه.

## العمل مع أشخاص آخرين

امنح كل شخص الوصول إلى المشاريع التي يحتاجها فقط، من إعدادات المشروع ثم Collaborators and teams. صلاحية Read للاطلاع، وWrite للمطور الذي يعدّل، وAdmin لإدارة المشروع. احتفظ بدور Owner لعدد محدود من الأشخاص الموثوقين.

الصلاحية الأساسية للمؤسسة مضبوطة على None: العضوية وحدها لا تمنح الوصول إلى المشاريع الخاصة؛ أضف الوصول لكل مشروع عند الحاجة.

## الأمان

- فعّل التحقق بخطوتين من إعدادات حسابك الشخصي، واحفظ رموز الاسترداد في مكان آمن.
- بعد تفعيله عند جميع الأعضاء، يستطيع مالك المؤسسة فرضه من Settings ثم Authentication security. راجع تنبيه GitHub عن أثره على الأعضاء والمتعاونين قبل التطبيق.
- لا ترفع كلمات مرور، مفاتيح API، ملفات .env، بيانات عملاء، أو نسخ قواعد بيانات.
- استخدم Secrets في إعدادات Actions عند الحاجة إلى مفاتيح النشر.
- عند انكشاف مفتاح، ألغِه وبدّله فورًا؛ حذف الملف وحده لا يزيله من تاريخ Git.
- المستودع Private لا يعني أن الموقع المنشور منه خاص. راجع خصوصية الاستضافة بشكل مستقل.

## ما الذي جهّزناه؟

مستودع .github يحتوي صفحة المؤسسة، وتعليمات المساهمة، وسياسة الإبلاغ الأمني، وقوالب المشاكل والاقتراحات وطلبات الدمج. يستخدم GitHub ملفات المجتمع الافتراضية في المشاريع المؤهلة التي لا تملك ملفات بديلة؛ راجع ظهور القوالب عند إنشاء كل مشروع.

الموقع والبريد مضافان للملف العام، والدومين موثّق لدى المؤسسة. توثيق الدومين يثبت التحكم به، ولا ينقل ملكية أي مستودع أو موقع تلقائيًا.

ابدأ بالخطة المجانية. راجع احتياجك قبل شراء خطة مدفوعة؛ بعض ميزات الحماية المتقدمة للمستودعات الخاصة تحتاج ترقية.
